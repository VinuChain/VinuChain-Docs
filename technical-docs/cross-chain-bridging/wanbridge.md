# Wanbridge

VinuChain has partnered with Wanbridge to allow the easy transfer of $VC between the BNB Chain and VinuChain.

Simply go to [https://bridge.wanchain.org/#/?asset=VC\&from=VinuChain](https://bridge.wanchain.org/#/?asset=VC\&from=VinuChain) and select the transfer route you wish to make.
