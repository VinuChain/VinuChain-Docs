# REST API

## REST API

REST API methods are used to render the UI.&#x20;

These can be accessed and used to get many types of information from [VinuExplorer](https://vinuexplorer.org).

**Methods, parameters, and schemas are available at:** [**https://vinuexplorer.org/api-docs**](https://vinuexplorer.org/api-docs)
