# Connect to Mainnet

## Add VinuChain Network

VinuChain Mainnet went live as of September 21, 2023.&#x20;

Here are the network details to connect on Metamask / Trust Wallet:

* Network Name: VinuChain
* New RPC URL: [https://rpc.vinuchain.org](https://rpc.vinuchain.org) or [https://vinuchain-rpc.com](https://vinuchain-rpc.com)
* Chain ID: 207
* Currency symbol: VC&#x20;
* Block Explorer URL: [https://vinuexplorer.org](https://vinuexplorer.org)
