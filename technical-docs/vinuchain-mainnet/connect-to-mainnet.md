# Connect to Mainnet

## Add VinuChain Network

VinuChain Mainnet went live as of September 21, 2023. The network now runs
the **ELEMONT** feature set, including SfcV2, Shanghai/Cancun/Prague EVM
equivalence, EIP-7702 set-code transactions, and the `vc_*` RPC namespace.

Here are the network details to connect on Metamask / Trust Wallet:

* Network Name: VinuChain
* New RPC URL: [https://rpc.vinuchain.org](https://rpc.vinuchain.org)
* Chain ID: 207
* Currency symbol: VC&#x20;
* Block Explorer URL: [https://vinuexplorer.org](https://vinuexplorer.org)
