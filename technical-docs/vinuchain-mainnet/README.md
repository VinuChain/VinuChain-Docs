# VinuChain Mainnet

VinuChain mainnet is the production network (chain ID `207`), running the
**ELEMONT** release. The ELEMONT hard-fork activates SfcV2, Shanghai, Cancun,
Prague (EIP-7702 set-code transactions), and the Elemont consensus fixes on
mainnet, along with the `vc_*` RPC namespace, `vc_getPaybackBalance`, and
`eth_config`/`vc_config`. This section covers connecting a wallet to mainnet
and running mainnet nodes.

For the full ELEMONT feature set, operator prerequisites, and new RPC surface,
see [VinuChain ELEMONT Upgrade](./elemont-upgrade.md).

For all chain IDs, RPC endpoints, and explorer URLs in one place, see
[Network Details](../network-details.md).
